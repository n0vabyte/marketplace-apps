# Discourse

Ansible playbook for deploying [Discourse](https://www.discourse.org/) — an open-source
discussion platform — via the official `discourse_docker` `launcher` tooling, on a single Akamai
Compute Instance.

> Scaffolded by `/app-ansibilize`. Full documentation (architecture, scaling, sample workload,
> gotchas) is written at the PR phase — see `.documentation/discourse/` for the backport's
> research, manual-install walkthrough, and architecture decisions in the meantime.
